OPSECcord - custom Discord app

Setup (PowerShell, inside this folder):
  npm install
  npm start

Then:
  1. Save your NitroShield plugin file as plugins\NitroShield.plugin.js
  2. Restart the app (npm start). Log in once; the login is remembered.
  3. Ctrl+Alt+K opens the Control Center, Ctrl+Alt+B toggles blur mode.
  4. Ctrl+Shift+I opens DevTools if something doesn't load.

Edit the accent colors at the top of public\css\discord-theme.css.
